Bundled Bash runtime: source, license, and modification notice
================================================================

Ostadix Terminal 0.1.6 derives its standalone Bash runtime from these Termux
aarch64 package payloads:

  GNU Bash 5.3.15                    GPL-3.0-or-later
  GNU Readline 8.3.3                 GPL-3.0-or-later
  GNU libiconv 1.18-1                LGPL-2.1-or-later
  Termux libandroid-support 29-1     Apache-2.0 and MIT-family licenses
  ncurses 6.6.20260307+really6.5.20250830
                                      ncurses permissive license

The APK build makes only Android packaging metadata changes on 2026-09-01:
it replaces Termux-private DT_RUNPATH entries with the literal ${ORIGIN},
renames the Bash executable for PackageManager extraction, renames two
version-suffixed shared-library files to names ending in .so, and updates the
matching DT_NEEDED and DT_SONAME strings from libreadline.so.8 to
libreadline_8.so and from libncursesw.so.6 to libncursesw_6.so. No program
source is changed. The complete transformation is implemented by
apps/android-terminal/tools/scrub_elf_runpath.py and
apps/android-terminal/build.sh in the Ostadix-lang source tree:

  https://github.com/lostadi/Ostadix-lang

Android supports ${ORIGIN} beginning at API 24. Testing on the build device
also found a linker namespace that did not search the main executable's valid
RUNPATH, so the app supplies a sanitized LD_LIBRARY_PATH containing only its
PackageManager-owned nativeLibraryDir to the non-root Bash child. That
variable is never placed in the app process, system-shell fallback, or
explicit /system/bin/su environment.
